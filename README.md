# Saturday 21 November 2026 — Front Page

A single-page news infographic: 35 stories across 7 regions, all dated Saturday
21 November 2026. The lead stories cover the COP31 climate summit running past
its deadline, five Houthi missiles shot down over Saudi Arabia, and a magnitude
6.7 earthquake shaking central Peru, with a numbered brief grid, a world map,
and a "Date check" column below.

## Run it

```bash
node main.ts
```

The script copies `entry.png` into `MAKEFUN_OUTPUT_DIR` (default `/output`) and
reports the copied byte count on stderr.
